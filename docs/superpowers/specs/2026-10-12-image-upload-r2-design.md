# 图片上传功能设计：R2 对象存储 + 文件库

日期：2026-10-12
状态：已获用户确认，实施中

## 需求

- 全部图片字段（头像/favicon/背景图/链接图标/二维码/相册/宠物）支持上传，保留填 URL 的旧方式（兼容外链）。
- 文件库完整管理：**区分「使用中（标注被哪处在用）/ 未使用」**，可筛选、删除。
- 存储走 Cloudflare R2；文件经 `linktree.huolin.puppyis.cool/files/...` 访问（不加新域名）。

## 决策与依据

| 决策 | 理由 |
|------|------|
| R2 而非 D1 存图 | D1 单行/BLOB 上限 2MB、单库 500MB（官方 Limits），照片/视频放不下；R2 免费 10GB·月 + 流量永久免费 |
| Worker 代理上传（非预签名直传） | 单文件 ≤20MB，中转无压力；复用 JWT 鉴权、密钥不暴露；实现约为预签名方案的 1/3 |
| `/files/<key>` 同域访问 | 用户选择不加新域名；Worker 从 R2 取对象返回，带长缓存 |
| SVG 响应加 `Content-Security-Policy: sandbox` | 同域下发用户上传的 SVG 有脚本执行风险，sandbox 头中和 |
| `files` 元数据表 | 配额统计（SUM(size)）与文件库列表；删除时同步清理 |
| 应用层配额守卫 | R2 免费 10GB（**账号级共享**）超出后按 $0.015/GB·月计费（非硬上限）；**本站配额 2GB**（给其他 R2 项目留空间），≥95%（约 1.9GB）拒绝上传 + 后台用量条，保证零扣费 |

## 上传限制（双层防护）

| 类型 | 上限 | 前端 | 后端 |
|------|------|------|------|
| 图片（jpeg/png/gif/webp/svg） | 5 MB | 选文件即校验，拒绝并提示 | Content-Length + 实际字节数双检 → 400 |
| 视频（webm/mp4） | 20 MB | 同上 | 同上 |

平台 Worker 请求体上限 100MB 永远不会被触及。

## 数据模型

`files` 表（迁移 0002）：`key`（PK，`uploads/YYYY/MM/随机名.后缀`）、`name`（原文件名）、`size`（字节）、`mime`、`created_at`。

字段引用形态：图片字段存 `/files/<key>` 路径；**使用判定实时扫描** pages/links/gallery/pet/site_config 的图片字段与 `files.key` 比对，不加冗余关联表。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/admin/files` | multipart 上传（JWT；类型/大小/配额校验），返回 `{ key, url, name, size, mime }` |
| GET | `/api/admin/files` | 文件列表（含 `used_by` 使用标注）+ `total_bytes` / 配额 |
| DELETE | `/api/admin/files?key=` | 删 R2 对象 + 元数据行 |
| GET | `/files/*`（公开） | 从 R2 读对象返回，长缓存 + `CSP: sandbox` + `nosniff` |

## 前端（admin）

- 新「文件库」标签页：用量条（已用 / 2GB，≥85% 变黄）、上传按钮、筛选（全部/使用中/未使用）、卡片（预览/文件名/大小/使用标注/删除）。
- 各图片输入框旁加「上传」按钮：选文件 → 上传 → 自动填入 `/files/...` 并标脏；URL 输入保留。

## 测试

类型白名单拒绝、超大小拒绝、配额守卫（≥95% 拒绝）、使用判定（被引用/未被引用）、`/files/` 访问与 SVG 安全头。
