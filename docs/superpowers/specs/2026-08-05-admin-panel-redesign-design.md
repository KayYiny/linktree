# 管理面板重做设计

## 概述

重做管理面板，采用深色主题 + Neo-Brutalism 风格，参考用户提供的设计图。改进 UX，新增修改密码功能。

## 设计原则

1. **深色主题**：背景 `#0a0a0a`，卡片白色，高对比度
2. **Neo-Brutalism**：粗边框（3px）、硬阴影（5px 5px 0）、小圆角
3. **亮色强调**：红色=活跃/删除，青色=新增，黄色=导出
4. **水平标签页**：替代侧边栏导航
5. **内联编辑**：链接用卡片式内联表单，非弹窗

## 功能模块

### 1. 链接管理
- 卡片式内联编辑
- 每个链接一个卡片，包含：
  - 图标预览
  - 显示名称、多语言键
  - 图标 URL、跳转链接
  - 二维码图片、备注
  - 备注多语言键
- 操作按钮：上移、下移、删除
- "+ 新增链接" 按钮

### 2. 相册管理
- 图片网格预览
- 支持拖拽排序
- 添加/删除图片

### 3. 宠物管理
- 按页面分组
- 内联编辑宠物图片和语录
- 多语言语录支持

### 4. 翻译管理
- 表格形式展示
- 支持搜索过滤
- 批量编辑

### 5. 设置
- **站点配置**：头像、用户名、favicon
- **修改密码**：当前密码、新密码、确认密码
- **修改用户名**

## 新增 API

```
POST /api/admin/change-password
Headers: Authorization: Bearer <token>
Body: { oldPassword: "xxx", newPassword: "xxx" }
Response: { success: true }
```

## 交互流程

1. **页面加载**：
   - fetch 所有数据
   - 渲染到各自标签页
   - 默认显示"链接管理"

2. **编辑数据**：
   - 直接在卡片/表格中编辑
   - 修改项自动标记

3. **保存数据**：
   - 点击"保存"按钮
   - 批量提交所有修改
   - 显示成功/失败提示

4. **导出/导入**：
   - 导出：打包为 JSON 下载
   - 导入：上传 JSON，预览后确认
